Ista stvar, u terminalu

Ovaj demo je web sučelje za isti engine. Za rad na stotinama slika, CLI je brži.

# instalacija
git clone https://github.com/Sebwebswiss/imageforge.git
cd imageforge
pip install -e .

# cijela mapa — pita koji format želiš
$ imageforge ./photos

  ✓  hero.jpg → hero.webp  89.2 KB  (-96.2%)
  ✓  logo.png → logo.webp  12.4 KB  (-94.1%)
  ✓  team.jpg → team.webp  128.4 KB (-89.7%)

# ili eksplicitno, za skripte i CI (bez pitanja)
$ imageforge ./photos --format avif --max-size 100 --recursive

# opcije
  --format {webp,avif,jpeg,png}   format izvoza
  -o, --output PATH               izlazna mapa
  -w, --width PX                  max širina (default 1200)
  -q, --quality 1-100             kvalitet (default 80)
  -s, --max-size KB               ciljana veličina datoteke
  -r, --recursive                 uključi podmape
  -f, --force                     konvertuj ponovo postojeće

Zašto radi

⚡

Automatska optimizacija veličine

Zadaš „maksimum 100 KB" i engine spušta kvalitet, a zatim i dimenzije dok datoteka ne stane. U memoriji, bez privremenih datoteka.

📐

EXIF orijentacija

Fotografije s telefona se više ne prikazuju rotirane — orijentacija se primjenjuje prije skaliranja.

🪟

Prozirnost

WebP, AVIF i PNG zadržavaju alpha kanal. JPEG nema alpha kanal, pa se slika stavlja na bijelu pozadinu.

📦

Batch i rekurzija

Cijela struktura mapa u jednoj naredbi. Već obrađene datoteke se preskaču, osim ako ne dodaš --force.

🔌

Python API

convert_image() i convert_directory() su obične funkcije — koristi ih u svojem kodu.

🛡️

Privatnost po zadanom

Ništa ne ide na server. Ovo je demo za browser; CLI radi lokalno na tvom disku.
