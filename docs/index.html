Why it works

    

      

        
⚡

        
Automatic size optimization

        
Set a “100 KB maximum” and the engine lowers quality, then dimensions, until the file fits. In memory, no temporary files.

      

      

        
📐

        
EXIF orientation

        
Photos from a phone no longer display rotated — orientation is applied before scaling.

      

      

        
🪟

        
Transparency

        
WebP, AVIF and PNG keep the alpha channel. JPEG has no alpha channel, so the image is placed on a white background.

      

      

        
📦

        
Batch and recursion

        
A whole folder structure in one command. Already-processed files are skipped unless you add --force.

      

      

        
🔌

        
Python API

        
convert_image() and convert_directory() are plain functions — use them in your own code.

      

      

        
🛡️

        
Private by default

        
Nothing goes to a server. This is the browser demo; the CLI runs locally on your disk.
